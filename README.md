# ☕ Coffee Shop Sales Dashboard (Excel Project)

## 📊 Project Overview

This project focuses on analyzing coffee shop sales data using Microsoft Excel. The goal is to transform raw transactional data into meaningful business insights through data cleaning, transformation, and interactive dashboard creation.

---

## 🎯 Objectives

* Clean and preprocess raw sales data
* Perform data transformation for time-based analysis
* Analyze customer behavior and sales trends
* Build an interactive and visually appealing dashboard
* Generate actionable business insights

---

## 🛠️ Tools & Technologies Used

* Microsoft Excel 2016
* Power Query (Data Cleaning & Transformation)
* Pivot Tables & Pivot Charts
* Data Visualization Techniques

---

## 🔄 Data Cleaning & Transformation

* Removed null and inconsistent values
* Converted data types (Date, Time, Numeric)
* Extracted:

  * Month Name
  * Day Name
  * Hour
* Created new calculated columns:

  * Total Sales = Quantity × Unit Price

---

## 📈 Key Metrics (KPIs)

* 💰 Total Sales
* 👥 Total Footfall (Number of Orders)
* 💳 Average Bill per Person
* 📦 Average Orders per Person

---

## 📊 Dashboard Features

* Sales analysis based on:

  * Hourly trends
  * Weekday trends
  * Store locations
* Category and size distribution using pie charts
* Top 5 best-selling products
* Interactive slicers (Month & Day) for filtering

---

## 💡 Key Insights

* Peak sales occur during morning hours (8 AM – 10 AM)
* Coffee category contributes the highest revenue share
* Some store locations generate higher revenue with similar footfall
* Weekdays (especially Thursday & Friday) show higher sales
* Large and Regular sizes are the most preferred by customers

---

## 📌 Project Highlights

* End-to-end data analysis using Excel
* Interactive and user-friendly dashboard
* Business-focused insights generation
